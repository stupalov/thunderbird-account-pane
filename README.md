# AccountPane

Расширение Thunderbird с разделённой панелью аккаунтов и папок, как в Postbox.

**Статус:** спецификация согласована; план реализации подготовлен для проверки. Установочного XPI пока нет.

## Согласованное поведение

- В верхней части левой панели отображается отдельный список аккаунтов.
- В нижней части — избранные и дерево папок выбранного аккаунта.
- Переключение аккаунта возвращает последнюю открытую папку этого аккаунта. При первом выборе открываются «Входящие», если они есть.
- Пункт «Все аккаунты» возвращает общий список папок.
- Отключение расширения возвращает обычную левую панель Thunderbird.
- Оформление следует выбранной теме; Postbird Tangaroa поддерживается первым.

## Оформление

Название и поведение дополнения не зависят от темы. Первая проверка оформления выполняется с
[Postbird Tangaroa](https://github.com/stupalov/postbird-tangaroa).
Тема и переключатель аккаунтов остаются отдельными проектами: тему можно использовать без этого расширения.

## Данные и доступ

По проекту расширение работает локально и управляет навигацией и отображением панелей.
Для встраивания в левую панель потребуется Thunderbird Experiment API, который при установке
запрашивает полный доступ к Thunderbird и компьютеру. Поведение реализации должно быть
ограничено функциями, описанными в спецификации.

Почта, пароли, адреса аккаунтов и содержимое профиля в этот репозиторий не включаются.
